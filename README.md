# EvEu Scanner — releases

Signed Android builds of **EvEu Scanner** (`app.evaaro.hht`), the Evaaro Europe production handheld app
for Chainway C72 devices. Installed and updated on managed devices through Scalefusion.

**Install a specific version (what Scalefusion uses):**
`https://github.com/Evaaro/eveu-scanner-releases/releases/download/v<version>/eveu-scanner-<version>.apk`

**Always the latest release:**
https://github.com/Evaaro/eveu-scanner-releases/releases/latest/download/eveu-scanner.apk

- This repository holds release APKs only. The source is private.
- Every APK is signed by the Evaaro release key, certificate SHA-256
  `80:3E:ED:6C:34:87:12:9B:FD:B4:84:E2:BF:83:E7:12:54:EC:96:39:08:A4:FA:26:C0:20:1E:18:3A:1D:A1:D9`.
  Do not install a build signed by anything else.
- The app does nothing without an Evaaro staff sign-in on a device registered by Evaaro.
- v0.42.0 was published as "Evaaro Scanner" (`evaaro-scanner*.apk`), before the rename.
